# CF1408F - Two Different

- 题目：[Codeforces 1408F](https://codeforces.com/problemset/problem/1408/F)
- 难度：Codeforces 2300
- 标签：构造、倍增、分治、重叠区间覆盖
- 完成情况：在引导下澄清任意函数的量词与符号化视角，独立推出 2 的幂长度块合并；根据区间覆盖提示补全任意规模构造并独立实现；已 AC
- 用时：未记录

## 题意

初始数组为 `a_i=i`。给定一个任意但固定的函数 `f:N×N->N`，一次操作选择两个位置 `x,y`，计算 `t=f(a_x,a_y)`，再把两个位置同时赋值为 `t`。

只根据 `n` 预先输出不超过 `5e5` 次操作，使得对于任意函数 `f`，全部操作结束后数组中至多存在两个不同的值。

数据范围：

```text
1 <= n <= 15000
```

## 最初的理解与卡点

初看题目时感觉任意函数的限制过强，并产生过“为什么不让所有 `f` 的输出都是 1”的疑问。这里真正的量词顺序是：先构造一套固定操作，再要求它对所有可能的 `f` 都有效；`f` 不是构造者可以选择或控制的。

澄清后，把一次操作理解为给两个位置连边并使其相等，同时注意到这不是并查集式的永久合并：一个位置参与后续操作时，可能离开此前的相等块。因此需要精心排列操作，让一批位置经历相同的函数调用过程。

## 引导过程

1. agent 建议把 `f` 的返回值视为形式符号。只有同一次操作写入的两个位置，或者以完全相同的有序参数调用 `f`，才可以无条件保证结果相等。
2. agent 将问题收缩到：已经存在两个等长且内部相等的块时，怎样把它们合成一个更大的相等块。
3. 随后独立给出倍增构造：先操作 `(1,2),(3,4),...` 得到长度为 2 的相等块；再操作 `(1,3),(2,4)` 合并成长度为 4 的块；继续用对应位置配对得到长度 `8,16,32,...` 的块，并判断操作数是 `O(n log n)`。
4. 对非 2 的幂规模，agent 提示利用“最终只需至多两种值”，并考虑两个长度为最大 2 的幂的区间。随后立即补全：分别从左右端点运行完整构造，两个区间覆盖整个数组，最终至多留下两种值。
5. 独立实现上述构造并提交通过。

## 关键观察

若两个长度均为 `s` 的块已经分别全部等于 `A` 和 `B`，按相同方向连接对应位置：

```text
(l+i, l+s+i), 0 <= i < s
```

每次函数调用的有序参数都是 `(A,B)`，所以每个位置最终都变为同一个值 `f(A,B)`。这样就能把两个长度为 `s` 的相等块合并成长度为 `2s` 的相等块。

有序参数的方向必须一致；题目没有保证 `f(A,B)=f(B,A)`。

## 最终算法

令

```text
m = 2^floor(log2(n)).
```

定义 `build(pos)`，把 `[pos+1,pos+m]` 统一：

1. 第 0 层合并相邻的长度 1 块。
2. 第 1 层合并相邻的长度 2 块。
3. 依次倍增，直到整个长度 `m` 的区间相等。

随后依次执行：

```text
build(0)
build(n-m)
```

即先统一前缀 `[1,m]`，再统一后缀 `[n-m+1,n]`。

## 正确性说明

### `build` 能统一一个 2 的幂长度区间

归纳证明。长度为 1 的块天然内部相等。若每个长度为 `2^i` 的小块已经内部相等，那么对相邻两块的对应位置按同一方向操作，每次调用 `f` 的参数都相同，所有 `2^(i+1)` 个位置会得到同一个返回值。因此第 `i` 层结束后，每个长度为 `2^(i+1)` 的块内部相等。完成 `k` 层后，整个长度 `m=2^k` 的区间相等。

### 最终至多有两个值

由 `m<=n<2m`，前缀 `[1,m]` 与后缀 `[n-m+1,n]` 的并覆盖 `[1,n]`。

第一次 `build` 后，前缀全部等于某个值 `A`。第二次 `build` 可以处理任意初始值，因此结束后整个后缀等于某个值 `B`；它可能覆盖前缀的重叠部分，但前缀中未被覆盖的位置仍为 `A`。所以最终所有位置的值都属于 `{A,B}`，至多有两个不同值。

## 复杂度

一次 `build` 的每一层进行 `m/2` 次操作，共有 `log2(m)` 层。运行两次：

```text
操作数：m log2(m)
构造时间：O(m log m)
额外空间：O(m log m)（保存输出操作）
```

当 `n<=15000` 时，`m<=8192`，最大操作数为：

```text
8192 * 13 = 106496 < 500000.
```
