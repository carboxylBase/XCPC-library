## 题意

在一个 `h × w` 棋盘中，从左上角 `(1,1)` 出发，每次只能向右或向下走一格，不能经过给定的 `n` 个黑格，求到达右下角 `(h,w)` 的路径数。

数据范围：

```text
1 <= h,w <= 1e5
1 <= n <= 2000
```

## 最初的观察

首先想到从所有单调路径中排除经过黑格的路径。但同一条路径可能经过多个黑格，如果逐个减去经过每个黑格的路径，就会产生重复扣除，因此存在容斥结构。

对于单个黑格 `(x,y)`，经过它的路径数量为：

```text
C(x+y-2, x-1) * C(h-x+w-y, h-x)
```

这是从起点到黑格、再从黑格到终点的路径数之积。

## 引导过程

1. 自己先识别出“经过多个黑格会重复计算”，判断需要处理容斥。
2. agent 让问题退化到单个黑格，自己立即写出前后两段路径数的乘积。
3. agent 询问两个黑格能够依次出现在同一路径上的条件，自己得到偏序关系：若先经过 `(x_1,y_1)` 再经过 `(x_2,y_2)`，必须满足 `x_2 >= x_1` 且 `y_2 >= y_1`。
4. agent 建议按照路径遇到的第一个黑格分类。自己随即补出核心转移：对黑格 `i`，减去所有位于其左上方的黑格 `j` 的首遇路径数，再乘从 `j` 到 `i` 的路径数。
5. 起初将黑格数量误看成 `1e5`，因而认为二次复杂度不可行；重新确认 `n <= 2000` 后，发现 `O(n^2)` 只有约四百万次转移，本题至此完成。

## 最终算法

将全部黑格按照坐标排序，并把终点 `(h,w)` 作为最后一个普通点加入序列。

设 `dp_i` 表示从起点到点 `i`，且在此之前没有经过任何黑格的路径数。对于点 `i=(x_i,y_i)`，先计算不考虑黑格时从起点到它的全部路径：

```text
C(x_i+y_i-2, x_i-1)
```

然后枚举所有满足 `x_j <= x_i` 且 `y_j <= y_i` 的更早黑格 `j`，扣除先到达 `j`、再从 `j` 走到 `i` 的路径：

```text
dp_i = C(x_i+y_i-2, x_i-1)
       - sum(dp_j * C(x_i-x_j+y_i-y_j, x_i-x_j))
```

当 `i` 是终点时，得到的 `dp_i` 就是答案。

## 正确性说明

考虑任意一条从起点到点 `i`、但经过了黑格的路径。沿路径方向观察，它存在唯一的第一个黑格 `j`。

- `dp_j` 统计从起点到 `j` 且此前没有经过黑格的前缀。
- 组合数 `C(x_i-x_j+y_i-y_j, x_i-x_j)` 统计从 `j` 到 `i` 的任意后缀。

因此，这条非法路径会在且只会在其第一个黑格 `j` 对应的转移中被扣除一次。扣除所有可达的黑格后，剩余路径恰好是不经过任何黑格的路径。

## 复杂度

预处理阶乘和逆阶乘到 `h+w`，每次组合数查询为 `O(1)`。

```text
时间复杂度：O(h+w+n^2)
空间复杂度：O(h+w+n)
```

## 实现要点

- 点应按照坐标排序，转移时仍需判断两个坐标是否都满足偏序关系。
- 所有减法及时加模，避免出现负数。
- 终点作为额外普通点参与同一递推，不应作为障碍处理。
- 真正参与二次 DP 的是黑格数量 `n <= 2000`，不是棋盘边长 `h,w <= 1e5`。

## 扩展思考

如果黑格数量真的提高到 `1e5`，这个递推会退化到 `O(n^2)`。转移权值

```text
C((x_i-x_j)+(y_i-y_j), x_i-x_j)
```

同时依赖两个坐标差，不能直接分离成普通二维偏序数据结构维护的源点项与终点项。因此，仅把 `n` 改成 `1e5` 会成为明显更困难的另一道题；CDQ 或树状数组不能直接套用。
