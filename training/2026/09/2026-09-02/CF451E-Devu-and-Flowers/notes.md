# CF451E - Devu and Flowers

- 题目：[Codeforces 451E](https://codeforces.com/problemset/problem/451/E)
- 难度：Codeforces 2300
- 标签：组合计数、生成函数、容斥、广义二项式定理、子集枚举
- 完成情况：在引导下补全生成函数系数公式，独立完成实现并排查错误；已 AC
- 用时：未记录

## 题意

有 `n` 种花，第 `i` 种最多有 `f_i` 朵。要求恰好选出 `s` 朵花，求满足

```text
x_1 + x_2 + ... + x_n = s
0 <= x_i <= f_i
```

的非负整数解数量，答案对 `1e9+7` 取模。

数据范围：

```text
1 <= n <= 20
0 <= s <= 1e14
0 <= f_i <= 1e12
```

## 最初的观察

先把第 `i` 种花的选择数写成生成函数：

```text
1 + x + x^2 + ... + x^{f_i}
```

全部种类相乘后，`x^s` 的系数就是答案。进一步独立发现有限等比数列可以拆成：

```text
prod(1 + x + ... + x^{f_i})
= prod(1 - x^{f_i+1}) / (1-x)^n
```

此时已经把限制集中到了分子，但一开始不知道如何求 `(1-x)^{-n}` 的系数。

## 引导过程

1. 自己先建立每种花的生成函数，并把乘积改写为 `prod(1-x^{f_i+1}) / (1-x)^n`。
2. agent 给出负整数次幂的系数公式：

   ```text
   (1-x)^{-n} = sum_{t>=0} C(t+n-1,n-1)x^t
   ```

   随后自己立刻补全算法：分子暴力展开为 `2^n` 个子集项，再与分母中对应次数的系数配对。
3. 因为对广义二项式定理不熟，继续追问并理解了恒等式

   ```text
   C(-n,t) = (-1)^t C(n+t-1,t)
   ```

   的定义与代数变形；虽然仍觉得这种推广的来源较抽象，但已经能使用这个定义。
4. 实现时先后遇到三类问题：分子两项的正负号写反、没有跳过负次数、直接用 `t` 下标访问阶乘数组导致 RE。
5. 改为利用对称性计算 `C(n+t-1,n-1)` 后，又发现逐项误乘了逆阶乘，以及 `res * (n+t)` 在取模前会溢出 `long long`。修正为先对因子取模、最后只乘一次 `(n-1)!` 的逆元后 AC。

## 最终算法

分子按子集展开。对任意子集 `T`，令

```text
d_T = sum_{i in T}(f_i+1)
```

则分子中对应项为：

```text
(-1)^|T| x^{d_T}
```

为了让整个乘积贡献 `x^s`，分母需要提供 `x^{s-d_T}`。当 `d_T <= s` 时，其贡献为：

```text
(-1)^|T| C(s-d_T+n-1,n-1)
```

所以答案是：

```text
sum_{T subseteq [1,n], d_T<=s}
    (-1)^|T| C(s-d_T+n-1,n-1)
```

由于 `n <= 20`，可以直接枚举全部子集。组合数的上标可能达到 `1e14`，但下标 `n-1 <= 19`，因此用长度至多 19 的下降幂计算：

```text
C(t+n-1,n-1)
= (t+n-1)(t+n-2)...(t+1) / (n-1)!
```

每个因子先对模数取模，避免乘法溢出。

## 正确性说明

对每种花，`1+x+...+x^{f_i}` 的 `x^{x_i}` 项唯一对应选择 `x_i` 朵，因此原生成函数中 `x^s` 的系数恰好等于合法方案数。

将每个有限等比数列写成 `(1-x^{f_i+1})/(1-x)` 后，选择分子中的 `-x^{f_i+1}` 等价于把第 `i` 个变量越过上界的部分通过容斥扣除。固定子集 `T` 后，分子已占用次数 `d_T`，分母 `(1-x)^{-n}` 中 `x^{s-d_T}` 的系数为 `C(s-d_T+n-1,n-1)`。对子集符号 `(-1)^{|T|}` 求和，正是对所有上界违规事件的容斥，所以所得系数等于原问题答案。

## 复杂度

共有 `2^n` 个子集，每个组合数用 `O(n)` 次乘法计算：

```text
时间复杂度：O(n * 2^n)
空间复杂度：O(2^n)
```

## 实现要点与踩坑

- 通过版本见 [`solution.cpp`](solution.cpp)。
- 展开 `1-x^{f_i+1}` 时，不选该项的符号不变，选该项才令符号取反。
- 当 `s-d_T < 0` 时，该子集没有贡献，必须跳过。
- 不能按照巨大上标预处理阶乘；应利用下标 `n-1 <= 19` 很小这一条件。
- `inv[k]` 在代码中表示 `1/k!`，不是整数 `k` 的逆元；整个下降幂乘完后只乘一次 `inv[n-1]`。
- 即使最终要取模，`res * (t+i)` 也可能先发生 `long long` 溢出，因此必须写成 `res * ((t+i)%MOD) % MOD`。
- 归档版保留了通过代码使用广义组合数的写法；`C(-n,t)` 内部与调用处各处理一次 `(-1)^t`，二者抵消后得到分母的正系数。
