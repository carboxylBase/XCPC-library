- 完成情况：独立提出按周期余数枚举并二分周期数的方向，在引导下修正单调性理解与实现错误；NWPUOJ 已 AC
- 用时：未记录

## 题意

船从 `(x1,y1)` 出发，风按照长度为 `n` 的字符串周期性移动船。每天在受到风的位移之外，还可以主动向四个方向移动一步或不移动。求最少经过多少天可以到达 `(x2,y2)`，无解输出 `-1`。

数据范围：

```text
0 <= x1,y1,x2,y2 <= 1e9
1 <= n <= 1e5
```

## 最初的观察

首先想到枚举最终时刻在周期中的位置 `i`。经过若干完整周期后，风造成的位移是在固定向量上反复累加，再加上当前周期前 `i` 天的前缀位移，因此可以对完整周期数进行搜索。

一开始把风后位置到终点的距离理解成单峰函数，考虑三分；随后改为二分最早可达时刻，但担心周期长度为奇数时需要按照奇偶性分别处理。

## 引导过程

1. 自己提出“枚举周期内位置，再搜索完整周期数”的主体框架，并从三分进一步改为二分。
2. agent 指出真正单调的不是距离本身，而是可达性。经过 `t` 天后，若只考虑风的位置为 `(X_t,Y_t)`，可达终点的充要条件是：

   ```text
   |X_t-x2| + |Y_t-y2| <= t
   ```

3. 由于题目允许当天不主动移动，不存在必须走满 `t` 步造成的奇偶限制；而且一旦可达，下一天可以用主动移动抵消当天的风，因此之后仍然可达。
4. 首次实现中虽然计算了周期前缀位移 `a`，却没有把它加进风后坐标，同时把可主动移动的天数误写成完整周期数 `mid`。
5. 第一次修正后加入了前缀位移，但判定仍写成 `dis <= mid`。再次确认 `mid` 表示周期数、总天数为 `mid*n+i` 后修正判定，提交通过。

## 最终算法

归档代码保留本次实际通过的“枚举余数 + 二分周期数”实现。

先计算一个完整风周期的位移 `period`。枚举 `i=0,1,...,n-1`，用 `prefix` 维护当前周期前 `i` 天的风位移。若已经经过 `cycles` 个完整周期，则：

```text
days = cycles * n + i
wind_position = start + cycles * period + prefix[i]
```

在这 `days` 天里，主动移动能够修正任意曼哈顿距离不超过 `days` 的位移，所以判定条件为：

```text
manhattan(wind_position, target) <= days
```

固定 `i` 后，该判定关于 `cycles` 单调。一个完整周期的位移向量的曼哈顿长度不超过 `n`；若当前周期数已经可达，再增加一个周期，风后位置到终点的距离至多增加 `n`，同时可用天数也恰好增加 `n`，所以仍然可达。对每个 `i` 二分第一个可行的 `cycles`，取所有余数中的最小总天数。

## 正确性说明

固定总天数 `days`，先只施加风，得到位置 `P`。每天至多进行一次主动单位移动，因此主动移动的总曼哈顿长度不超过 `days`；若终点与 `P` 的曼哈顿距离大于 `days`，必然不可达。

反之，若该距离不超过 `days`，可以分别沿横纵坐标使用恰好等于该距离的主动移动，其余天选择不移动，于是能够到达终点。因此判定条件既必要又充分。

任意非负天数都能唯一写成 `cycles*n+i`，其中 `0 <= i < n`。算法枚举了所有可能的 `i`，并利用上述单调性找到每个 `i` 下最小的可行周期数，所以最终取到的就是全局最少天数。若所有余数都不存在可行周期数，则答案为 `-1`。

## 复杂度

设二分周期数的上界为 `C`：

```text
时间复杂度：O(n log C)
空间复杂度：O(1)
```

还可以直接预处理长度为 `n` 的全部风位移前缀，再对总天数二分，从而做到 `O(n+log V)`；本次提交采用的是自己最初提出并最终通过的余数枚举版本。

## 实现要点与踩坑

- 通过版本见 [`solution.cpp`](solution.cpp)。
- `cycles` 是完整周期数，`days=cycles*n+i` 才是经过的总天数；可主动修正的距离上限必须与 `days` 比较。
- 风后坐标必须同时包含完整周期位移与周期内前缀位移：`start+cycles*period+prefix[i]`。
- 枚举 `i` 时先使用当前 `prefix` 判定，再加入 `s[i]`，这样它恰好表示前 `i` 天的位移。
- 允许“不移动”消除了主动移动步数的奇偶限制。
- 本地调试宏、`all.hpp` 和 `freopen("input.txt",...)` 已从归档版本中移除。
