# CF1342E - Placing Rooks

- 题目：[Codeforces 1342E](https://codeforces.com/problemset/problem/1342/E)
- 难度：Codeforces 2300
- 标签：组合计数、容斥、指数生成函数、满射、第二类斯特林数
- 完成情况：独立推出主体分类与指数生成函数，在引导下完成系数提取并实现；已 AC
- 用时：未记录

## 题意

在 `n × n` 棋盘上放置恰好 `n` 个车，要求：

1. 每个空格所在的行或列至少有一个车；
2. 恰好有 `k` 对车互相攻击。

同一行或列中的两个车只有在它们之间没有其他车时才算互相攻击。求摆法数，对 `998244353` 取模。

数据范围：

```text
1 <= n <= 2e5
0 <= k <= n(n-1)/2
```

## 最初的观察

首先独立抓住了覆盖条件的结构：

- 如果存在空行，为了覆盖该行的所有格子，每一列都必须有车；
- 反过来，如果存在空列，每一行都必须有车。

所以全部合法摆法是“每行都有车”和“每列都有车”两个集合的并。二者对称，可以先计算一种，再乘二；交集要求每行、每列各一个车，只在 `k=0` 时出现，共有 `n!` 种，需要减去一次。

## 从列容量到满射

考虑每行都有车。总共恰好有 `n` 个车和 `n` 行，因此每行恰好一个车。

假设恰好有 `m` 个非空列，第 `i` 个非空列有 `c_i` 个车。该列相邻的车之间产生 `c_i-1` 对攻击关系，因此

```text
k = sum(c_i-1)
  = n-m
```

也就是说非空列数不是枚举量，而被唯一确定为：

```text
m = n-k
```

最初尝试只统计正整数拆分 `c_1+...+c_m=n`，随后意识到每一行有标号：固定列容量后还要乘多项式系数

```text
n! / (c_1! c_2! ... c_m!)
```

这自然引出了指数生成函数。

## 引导过程

1. 自己先完成“每行都有 / 每列都有”的并集分类，并识别出交集为 `k=0` 时的 `n!` 个排列矩阵。
2. 对每行都有车的情形，自己按非空列容量 `c_i` 分组；agent 提醒总车数固定为 `n`，于是得到攻击对数 `k=n-m`，从而 `m=n-k`。
3. 自己修正了仅统计容量拆分的遗漏，写出多项式系数 `n!/(c_1!...c_m!)`，并想到用指数生成函数描述。
4. 一度认为可以让全部列的生成函数包含常数项来表示空列；agent 指出这样会混合所有非空列数。自己随即理解：`k` 已把 `m` 固定，必须提取恰好 `m` 个非空列。
5. 得到固定所选列后的生成函数 `(e^x-1)^m` 后，起初考虑多项式快速幂和形式幂级数对数。agent 提示把它当作关于 `e^x` 的普通二项式展开。
6. 自己补出关键系数提取：`e^{ix}=sum i^j x^j/j!`，所以 `[x^n]e^{ix}=i^n/n!`；外部的 `n!` 恰好抵消，最终只需枚举容斥项并快速幂。
7. 实现阶段依次修正了题目模数、漏乘行列对称因子 `2`、`k=0` 错误输出 `1`，以及过大的阶乘预处理上界，最终 AC。

## 最终算法

若 `k >= n`，则 `m=n-k <= 0`，不存在合法摆法，答案为零。以下考虑 `0 <= k < n`，令 `m=n-k`。

先计算每行恰好一个车、恰好使用 `m` 列的摆法数。

1. 从 `n` 列中选择实际使用的 `m` 列，有 `C(n,m)` 种。
2. 将 `n` 个有标号的行映射到这 `m` 个有标号的列，并要求每列至少被使用一次，即计算满射数量。

固定列集合后的指数生成函数是：

```text
n! [x^n] (e^x-1)^m
```

利用二项式定理：

```text
(e^x-1)^m
= sum_{i=0}^m (-1)^(m-i) C(m,i)e^{ix}
```

而

```text
[x^n]e^{ix} = i^n/n!
```

所以满射数量为：

```text
surj(n,m)
= sum_{i=0}^m (-1)^(m-i) C(m,i)i^n
```

一个方向的答案为：

```text
one = C(n,m) * surj(n,m)
```

行、列两个方向对称，因此先乘二。若 `k=0`，两个集合的交集是 `n!` 个排列矩阵，再减去一次：

```text
answer = 2 * one - [k=0] * n!
```

实现中直接特判 `k=0` 输出 `n!`。

## 正确性说明

任意合法棋盘若存在空行，则每列必须有车；若不存在空行，则每行都有车。因此每个合法棋盘必然属于上述两个集合之一，反之任一集合中的摆法显然覆盖所有空格。

在“每行都有车”的集合中，每行恰好一个车。若有 `m` 个非空列，则各列按顺序排列的相邻车对总数是 `sum(c_i-1)=n-m`，所以满足攻击对数 `k` 当且仅当 `m=n-k`。选择列后，把行分配给列且不允许空列恰好是一张满射；容斥公式逐一排除至少一个目标列未被使用的函数，因此准确统计全部满射。

最后，两个对称集合的交集要求每行、每列各一个车，恰好是排列矩阵，攻击对数只能为零且共有 `n!` 个。由集合并的容斥原理，最终公式恰好统计所有合法摆法一次。

## 复杂度

预处理阶乘和逆阶乘为 `O(n)`。容斥枚举至多 `n+1` 项，每项进行一次快速幂：

```text
时间复杂度：O(n log n)
空间复杂度：O(n)
```

## 实现要点与踩坑

- 通过版本见 [`solution.cpp`](solution.cpp)。
- 题目模数是 `998244353`，不是常用的 `1e9+7`。
- 最大合法攻击对数实际只有 `n-1`；`k >= n` 时直接输出零。
- 容斥和已经等于 `n![x^n](e^x-1)^m`，不应再额外乘除 `n!`。
- 只计算一个方向会少一倍；`k>0` 时行覆盖和列覆盖两类不相交。
- `k=0` 时不能简单乘二，因为两个集合完全重合，答案为 `n!`。
- 归档版移除了本地 `all.hpp`、文件重定向和计时代码，并把阶乘上界收紧到题目所需的 `200005`。
- 事后看，满射数量也可以写成 `m! S(n,m)`，其中 `S(n,m)` 是第二类斯特林数；本题的推导过程并未预先套用该结论，而是从指数生成函数和容斥自行得到公式。
