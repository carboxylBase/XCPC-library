# CF2026E - Best Subsequence

- 题目：[Codeforces 2026E](https://codeforces.com/problemset/problem/2026/E)
- 难度：Codeforces 2500
- 标签：图论建模、二分图、最大独立集、最小点覆盖、最大匹配、网络流

## 题意

给定长度为 `n` 的非负整数数组 `a`，可以选择任意子序列 `b`，空子序列也允许。定义其价值为：

```text
|b| - popcount(b1 OR b2 OR ... OR b|b|)
```

求最大可能价值。数据范围为 `n <= 100`、`0 <= a_i < 2^60`。

## 最初的观察

自己首先注意到减号不便直接处理，并利用总位数固定为 `60`，将目标改写为：

```text
选中的数字数量 + 最终 OR 中为 0 的位数 - 60
```

因此可以把每个“选择数字”和每个“让某一位保持为 0”都看成一个价值为 `1` 的决策。

如果数字 `a_i` 的第 `j` 位为 `1`，那么下面两个决策不能同时成立：

```text
选择数字 i
让第 j 位保持为 0
```

自己由这种二选一的冲突关系判断出问题应当能够使用最小割建模，但当时忘记了最大独立集、最小点覆盖与二分图最大匹配之间的对应关系。

## 冲突二分图

建立一张二分图：

- 左部有 `n` 个数字节点；选择节点 `i` 表示将 `a_i` 放入子序列。
- 右部有 `60` 个二进制位节点；选择节点 `j` 表示最终 OR 的第 `j` 位保持为 `0`。
- 当且仅当 `a_i` 的第 `j` 位为 `1` 时，在数字节点 `i` 与位节点 `j` 之间连边。

一条边的两个端点代表两个不能同时采用的决策。因此，任意一组合法决策恰好构成该二分图的一个独立集。

反过来，固定选中的数字集合 `X` 后，所有未在 `OR(X)` 中出现的位都与 `X` 没有冲突。因为每个这样的位都能额外贡献 `1`，最优独立集一定会把它们全部选入。因此最大独立集大小恰好等于：

```text
max_X (|X| + zero_bits(OR(X)))
```

原问题的答案即为最大独立集大小减去 `60`。

## 从最大独立集到最大匹配

任意图中，一个集合是点覆盖，当且仅当它的补集是独立集，所以：

```text
最大独立集大小 = 总点数 - 最小点覆盖大小
```

本题的冲突图是二分图。根据 König 定理：

```text
二分图最小点覆盖大小 = 二分图最大匹配大小
```

设最大匹配大小为 `matching`，冲突图共有 `n + 60` 个点，于是：

```text
最大独立集大小 = n + 60 - matching
原题答案       = n + 60 - matching - 60
               = n - matching
```

## 网络流实现

按标准二分图匹配建网络：

1. 源点向每个数字节点连容量为 `1` 的边。
2. 若 `a_i` 的第 `j` 位为 `1`，从数字节点 `i` 向位节点 `j` 连容量为 `1` 的边。
3. 每个位节点向汇点连容量为 `1` 的边。
4. 跑最大流得到二分图最大匹配 `matching`。
5. 输出 `n - matching`。

中间边写成 `INF` 也不会改变最大流值，因为每个数字节点的总流入和每个位节点的总流出都至多为 `1`；若直接从最小割角度解释冲突约束，使用 `INF` 会更直观。

## 正确性说明

构造的二分图中，每条边恰好描述一对不可同时成立的决策，因此合法决策集合与独立集一一对应。

对于任意选出的数字集合，把最终 OR 中所有为 `0` 的位节点加入后，就得到价值为 `|X| + zero_bits(OR(X))` 的独立集；反过来，任意独立集中的数字节点不会与其中的零位节点冲突，补齐所有仍可保持为 `0` 的位后不会变差。因此原目标加上常数 `60` 等于二分图最大独立集大小。

再由独立集与点覆盖的补集关系以及 König 定理，最大独立集大小为 `n + 60 - matching`，故原问题答案为 `n - matching`。

## 复杂度

图中有 `n + 60` 个普通节点，二分图边数至多为 `60n`。

使用任意能够通过本数据范围的二分图匹配或最大流算法即可。若使用 Hopcroft--Karp，时间复杂度为：

```text
O(60n * sqrt(n + 60))
```

空间复杂度为 `O(60n)`。

1. 看到题目后，自己首先判断“很像网络流”。
2. agent 曾给出另一种等价改写：最小化“未选数字数 + 被启用位数”，并提示这是选择依赖形式的最小割。这个改写不是自己最初想到的路线。
3. 自己随后澄清原始思路实际是最大化“选择的数字数 + OR 中为 `0` 的位数”，并已经观察到数字选择与零位选择之间存在不共存关系。
4. agent 将这种冲突关系对应到二分图最大独立集，并补充“最大独立集 = 总点数 - 最小点覆盖”以及 König 定理。
5. 自己据此恢复出标准网络：源点连左部、右部连汇点，跑最大流后用总点数减最大流；最后进一步消去额外的 `60` 个位节点常数，得到答案 `n - maxflow`。

## 容易混淆的点

- 本题使用的是**最大独立集**；所谓“最小独立集”允许直接取空集，没有这里需要的优化意义。
- 一般图最大独立集是困难问题；这里能够转成最大匹配，关键在于冲突图天然是二分图。
- `n + 60 - matching` 是冲突图的最大独立集大小，还必须减去目标改写时添加的常数 `60`。
- 数值为 `0` 的数字节点没有连接任何位节点，它必然可以加入独立集，这与选择 `0` 永远不会增加 OR 的 popcount 一致。
