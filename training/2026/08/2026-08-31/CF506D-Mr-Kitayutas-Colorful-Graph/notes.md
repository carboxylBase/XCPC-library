## 题意

给定一张 `n` 个点、`m` 条带颜色无向边的图。每次询问两个节点 `u,v`，求有多少种颜色满足：只使用该颜色的边时，`u,v` 处于同一个连通块。

数据范围为：

```text
2 <= n <= 1e5
1 <= m <= 1e5
1 <= q <= 1e5
```

## 最初的观察

先固定一种颜色。假设这种颜色有 `k` 条边，那么它涉及的非孤立点至多为 `2k`，能够产生贡献的点对数量是 `O(k^2)`。

因此，边数较少的颜色可以直接求出各个单色连通块，并枚举连通块内部的点对。每枚举到一个询问点对，就给这个询问的答案增加一种颜色贡献。

这个 `k^2` 的代价自然启发了按照颜色边数做根号分治。

## 思考过程

1. 自己首先观察到：一种颜色只有 `k` 条边时，涉及的点数也是 `O(k)`，所以暴力枚举连通点对的复杂度是 `O(k^2)`。
2. 设轻颜色的边数不超过阈值 `B`。所有轻颜色的总代价满足 `sum(k_c^2) <= B * sum(k_c) <= mB`，因此取根号阈值时可以接受。
3. 随后独立补出重颜色部分：边数超过 `B` 的颜色最多只有 `m/B` 种。对每一种重颜色建立单色连通块，然后遍历所有询问判断两个端点是否连通，总复杂度为 `O(qm/B)`。
4. 取 `B` 为 `sqrt(m)` 量级后，总复杂度为 `O(mB + qm/B)`；在 `m,q` 同阶时即 `O((m+q)sqrt(m))`，至此完成整体算法。
5. agent 在推导过程中只修正了复杂度记号：重颜色部分一般应写成 `qm/B`，只有取 `B = sqrt(m)` 后才与 `qB` 同阶；没有提供下一步算法提示。随后自己写出初版代码，并在调试中定位实现问题。

第一次超时来自轻重判断中的笔误：写成了 `e.size() > B`，这里取得是整个颜色数组的长度，导致几乎所有颜色都进入重颜色分支，复杂度退化为 `O(mq)`；应判断当前颜色的 `e[i].size()`。

修正该处并补上重颜色处理后的并查集清理后，仍有两项需要处理：

- 重颜色直接遍历原始询问数组；相同询问出现多次时，同一个答案项会被重复累加。应先规范化点对方向并生成去重后的询问集合，重颜色只扫描不同询问。
- 轻颜色枚举点对时使用 `map<pair<int,int>, int>` 查询，给 `O(mB)` 的主体又附加了 `log q` 和较大的常数。应将规范化点对编码后放入哈希表，每个点对只查询一次。

## 轻颜色

设颜色 `c` 有 `k_c <= B` 条边。先用并查集求出该颜色下的所有连通块，再枚举每个连通块内部的无序点对。

由于一个有 `k_c` 条边的颜色至多涉及 `2k_c` 个非孤立点，枚举代价为 `O(k_c^2)`。所有轻颜色的总代价为：

```text
sum(k_c^2) <= sum(B * k_c) <= mB
```

实现时只需要保存输入中真正出现过的询问点对。枚举到其他点对时直接忽略，从而把答案表的空间控制在 `O(q)`，避免保存最多 `O(mB)` 个不同点对。

## 重颜色

边数超过 `B` 的颜色数量至多为：

```text
m / B
```

对于每一种重颜色：

1. 合并这种颜色的全部边，得到每个相关节点的连通块编号。
2. 遍历所有不同的询问点对。
3. 如果询问的两个节点都在当前颜色中出现，并且连通块编号相同，就将答案加一。

这一部分的总复杂度为：

```text
O(qm / B)
```

所有颜色都是静态的，因此不需要莫队、可持久化并查集或可回滚并查集。

## 完整算法

1. 按颜色保存边。
2. 读入全部询问，将 `(u,v)` 规范化为 `u < v`，并合并重复询问。
3. 对每一种非空颜色建立单色并查集。
4. 如果该颜色是轻颜色，枚举各连通块内部的点对，只累计出现在询问表中的点对。
5. 如果该颜色是重颜色，遍历所有不同询问，直接检查两个端点是否在该颜色下连通。
6. 按原顺序输出每个询问点对累计到的颜色数量。

## 正确性说明

对于任意颜色 `c`，算法先准确求出只包含颜色 `c` 的图的连通块。

- 若 `c` 是轻颜色，算法枚举每个单色连通块内部的所有点对，因此一个询问恰好在两个端点被颜色 `c` 连通时获得一次贡献。
- 若 `c` 是重颜色，算法直接比较询问两个端点的单色连通块编号，同样恰好在二者被颜色 `c` 连通时获得一次贡献。

每种颜色被划入且只被划入轻、重两类中的一类，所以每种能够连接询问端点的颜色恰好贡献一次，不能连接的颜色不贡献。最终累计值就是题目要求的颜色数量。

## 复杂度

设根号阈值为 `B`。忽略排序和哈希表常数后：

```text
轻颜色：O(mB)
重颜色：O(qm / B)
```

总时间复杂度为：

```text
O(mB + qm / B + m log m)
```

取 `B = Theta(sqrt(m))`，且本题 `m,q` 同阶时，为：

```text
O((m + q) sqrt(m) + m log m)
```

空间复杂度为 `O(n + m + q)`。

## 后续实现时需要注意

- 轻颜色必须按连通块枚举点对，不能把这种颜色涉及的所有点直接两两配对。
- 查询 `(u,v)` 与 `(v,u)` 等价，应先统一端点顺序。
- 重复询问只计算一次，最后通过编号映射回原顺序。
- 只将出现在询问中的点对放入哈希表，避免轻颜色产生过多无用答案记录。
- 并查集数组可以在每种颜色涉及的节点上局部重新初始化，不需要每次初始化全部 `n` 个节点。
- 重颜色判断时要确认两个查询端点都在当前颜色中出现；否则两个未初始化节点不能被误判为连通。
