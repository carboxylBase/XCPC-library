## 最初的方向

最初感觉这道题应该从 Prüfer 序列出发，因为题目的本质是通过一个短序列唯一表示一棵树。直接尝试后发现，Prüfer 序列的每一项需要记录删去叶子时的邻居编号，而一次染色后得到的割边数量更容易反映节点的度数，无法自然地传递“邻居是谁”。

随后转向另一种树的序列编码：固定根和遍历顺序，记录每个节点的儿子数。只要采用 BFS 顺序，所有节点的儿子数就能唯一确定一棵有序有根树；忽略根和儿子的顺序后，得到的树与原树同构。

## 引导过程

1. 自己先提出固定一个根，按深度依次染色节点。根第一次染色后可以得到它的儿子数；之后染色一个节点时，它的父亲已经是黑色，从割边数的变化中可以继续得到该节点的儿子数。如果允许操作 `n` 次，这已经足以恢复整棵树。
2. 接着观察到 BFS 的最后一层全部是叶子，这些点的儿子数都是 `0`，不必逐个查询。如果存在一个根使最后一层至少有三个点，就已经满足 `n - 3` 的限制；但路径说明这种根不一定存在。
3. agent 提示根可以主动选择。于是选择原树的一个叶子作为根，它的儿子数固定为 `1`，根也不需要染色；再省去 BFS 最后一个必为叶子的节点，操作数降到 `n - 2`。
4. 距离限制还差一次。agent 提示所有儿子数并不独立，因为总儿子数等于边数。由此自己想到使用度数和 `2n - 2`：所有其他点的度数已知后，可以反推出倒数第二个点的度数。等价地，利用儿子数之和为 `n - 1` 反推它的儿子数，最终只需染色 `v_2` 到 `v_{n-2}`，恰好 `n - 3` 次。
5. 第一版实现中，BFS 访问新节点后忘记将其入队，并且输出染色序列时错误地包含了根。修正后，第二次运行采用剩余度数和 `D` 重建末尾结构；检查确认 BFS 编号下倒数第二个点最多只有最后一个节点作为儿子，所以最后只可能缺少边 `(n-1,n)`。
6. 清理后的实现通过了本地小规模随机树同构对拍；线上提交结果未记录。

## 染色带来的割边变化

设当前有 `a` 条黑白割边。将一个白色节点 `v` 染成黑色，并设它有 `b` 个黑色邻居。

- 原来的 `b` 条黑白边变成黑黑边。
- 其余 `deg(v) - b` 条白白边变成黑白边。

因此新的割边数 `a'` 满足：

```text
a' - a = deg(v) - 2b
```

这说明只要控制染色顺序，使 `b` 已知，就能从割边数量恢复节点的度数或儿子数。

## 选择根与染色顺序

选择原树中的任意叶子作为根，按照 BFS 顺序记节点为：

```text
v1, v2, ..., vn
```

其中 `v1` 是根。因为根是原树的叶子，所以它只有一个儿子 `v2`。

只染色：

```text
v2, v3, ..., v(n-2)
```

一共正好进行 `n - 3` 次操作。

第一次染色 `v2` 时还没有黑色节点，因此：

```text
a1 = deg(v2) = child(v2) + 1
```

所以：

```text
child(v2) = a1 - 1
```

对于 `i >= 3`，BFS 保证 `v_i` 的父亲已经染黑，而它的儿子尚未染色。树中不存在横叉边，因此它恰好只有一个黑色邻居：

```text
a(i-1) - a(i-2) = deg(v_i) - 2
                       = child(v_i) - 1
```

从而：

```text
child(v_i) = a(i-1) - a(i-2) + 1
```

这能恢复 `v2` 到 `v(n-2)` 的儿子数。

## 为什么还能省去三个点

有三个节点不需要直接通信：

1. `v1` 是作为根的原树叶子，所以 `child(v1) = 1`。
2. `vn` 是 BFS 顺序的最后一个节点，它不可能还有未编号的儿子，所以 `child(vn) = 0`。
3. 树有 `n - 1` 条边，每条边恰好对应一个父子关系，因此：

```text
sum(child(v)) = n - 1
```

知道其他所有节点的儿子数后，可以反推出 `child(v(n-1))`。

实现中使用了等价的度数和：

```text
sum(deg(v)) = 2n - 2
```

每恢复一条父子边，就从剩余度数和中减去 `2`。处理完 `v1` 到 `v(n-2)` 后，剩余值只可能是 `0` 或 `2`。如果是 `2`，说明 `v(n-1)` 还有唯一可能的儿子 `vn`，补上边 `(n-1,n)`。

## 根据 BFS 儿子数恢复树

重新将节点编号为 `1..n`，编号顺序就是原来的 BFS 顺序。

已知一个节点有 `c` 个儿子时，将接下来还没有使用的 `c` 个编号作为它的儿子。按 BFS 层依次处理所有已知节点，就能恢复所选择的有序有根树。虽然新编号与原树不同，但父子数量序列和 BFS 分组完全相同，因此去掉根与儿子顺序后，两棵树同构。

## 正确性总结

选择叶子作为根后，不染根仍能确定它只有一个儿子。第一次染色 `v2` 时割边数就是它的度数；此后每个被染节点恰好只有父亲一个黑色邻居，因此相邻割边数之差唯一确定它的儿子数。根、最后一个叶子的儿子数固定，倒数第二个节点的儿子数由总边数唯一确定，于是 Bombloong 能恢复完整的 BFS 儿子数序列。该序列按照 BFS 分组唯一构造出一棵与原树同构的树，所以通信方案正确。

## 实现细节与错误记录

- 第一阶段 BFS 发现新节点时必须同时标记、加入顺序并入队；只加入顺序而不入队会使遍历在根的下一层停止。
- 染色序列不能包含根。若 BFS 数组使用 0 下标，应输出 `order[1]` 到 `order[n-3]`。
- 通信序列中的第一个数直接给出 `v2` 的度数；只有后续节点使用相邻两项的差。
- 第二阶段按 BFS 顺序重新编号后，通信数组的位置可以直接作为新节点编号使用。
- 处理到 `n-2` 后，倒数第二个节点最多只有节点 `n` 这一个儿子，因此剩余度数和只能为 `0` 或 `2`。
- 提交版本需要移除私有的 `all.hpp`、`freopen`、调试宏和调试输出；逐边输出使用 `'\n'`，避免 `endl` 的频繁刷新。
