## 题意

给定 n 个互不相同的平面整数点。每次查询一个点 Q，要求从给定点中选择一些点作为顶点，构造严格包含 Q 的简单多边形，且顶点数最少；无解输出 -1。边上或顶点上的点不算严格内部。

3≤n≤100000，1≤q≤100000，各测试组 n、q 的总和分别不超过 100000，T≤20000。坐标在 [-10^9,10^9] 内，时限 1 秒。

## 用户的赛时思路与卡点

用户已经意识到题目与三角剖分密切相关：选一个凸包顶点作起点，对其他顶点形成三角扇，尝试寻找包含查询点的三角形。

对于落在剖分对角线上的点，用户观察到端点可能经过查询点两两配对，因此想到随机更换起点，若多次失败再暴力，并猜测特殊查询很少，可以记忆化。随后担心最优三角形可能需要非凸包点，无法确认整个模型。

这里需要区分“所有起点的扇形三角形都失败”和“不存在任意三个凸包顶点组成的合法三角形”。例如正六边形中心对任一起点都落在对面顶点的对角线上，随机起点仍失败，但第 1、3、5 个顶点组成的三角形可以严格包含中心。

## 最终分类

设去掉共线中间点后的凸包有 h 个顶点。

| 条件 | 最优答案 |
|---|---|
| h<3，或 Q 在凸包外部、边界上 | -1 |
| h=3，且 Q 严格在内部 | 3，输出整个三角形 |
| h≥5，且 Q 严格在内部 | 3，只需使用凸包顶点 |
| h=4，Q 严格在内部但不是对角线交点 | 3，凸包顶点足够 |
| h=4，Q 是对角线交点，有原点 R 同时不在两条对角线上 | 3，R 加两个凸包顶点 |
| h=4，Q 是对角线交点，所有原点都在两条对角线上 | 4，输出凸包 |

凸包包含全部给定点；任何所选多边形也包含在凸包内。因此凸包外部或边界上的点无法严格包含，无解判定必须先于构造。

## 扇形定位与局部五点构造

凸包 b[0…h-1] 按逆时针顺序排列，且没有边上的共线中间点。固定 s=b[0]，其余顶点方向在小于 180 度的内角范围内依次旋转。

对已确认严格位于凸包内部的 Q，二分最后一个满足

```text
cross(b[t]-b[0], Q-b[0]) >= 0
```

的下标 t。此时 1≤t≤h-2，下一顶点叉积为负。

- 若当前叉积大于零，扇形三角形 b[0],b[t],b[t+1] 严格包含 Q，直接输出。
- 若等于零，Q 在内部对角线 b[0]b[t] 上，此时 2≤t≤h-2。合并两侧三角形，四边形 b[0],b[t-1],b[t],b[t+1] 严格包含 Q。
- h≥5 时加入任意一个不在上述四点中的凸包顶点，从这五点中枚举三个点即可。

用户代码保留至多六个候选位置：0,t,t+1,t-1,t+2,t-2，后两项按 h 取模。t-2…t+2 这五个连续循环位置在 h≥5 时互不相同，因此候选中至少有五个不同凸包顶点，并包含所需四边形。位置 0 可能重复，但枚举时重新求三点凸包会排除重复或共线的退化三角形。最多枚举 C(6,3)=20 组，不影响渐近复杂度；归档未强行改成五点版本。

## 五点奇偶证明

保留严格包含 Q 的四边形，再加入第五个凸包顶点。这五个点本身仍处于严格凸位置，其凸包仍严格包含 Q。

假设没有任意三点组成的三角形严格包含 Q。以这五点中的任一顶点做三角扇，Q 必须落在一条经过该顶点的内部对角线上；否则已经得到合法三角形。因此每个顶点都必须与另一个顶点分处 Q 两侧并共线。

严格凸包中任一直线至多通过两个顶点，故这些关系形成顶点间的两两配对。五个顶点无法全部配对，矛盾。于是五点中必有合法三角形，顶点数 3 已达下界。

## 四边形特殊点与非凸包点

若凸四边形的查询点不在两条对角线的交点上，总能通过选择一条对角线，使 Q 严格落在它分出的某个三角形里。故四个三角形都失败、而 Q 严格位于四边形内部时，Q 必是两对角线交点。

设 Q=AC∩BD。若给定点 R 不在这两条直线上，它位于四条射线 QA,QB,QC,QD 划出的某个开扇区。假设 R 位于 QA 与 QB 之间，选对面的 C,D：射线 RQ 越过 Q 后会穿过线段 CD 的内部，故 Q 严格位于三角形 RCD 内。其他扇区同理。

因此预处理扫描全部原点，寻找同时满足下列条件的任意点即可：

```text
cross(C-A, R-A) != 0
cross(D-B, R-B) != 0
```

两条直线仅由固定凸包决定，扫描一次即可。搜索包括严格内点及被凸包删去的边上共线点，不能只扫描凸包，也不能只排除交点本身。

若全部原点位于这两条直线上，任意三点至少有两点同线。若两点在 Q 两侧，Q 在三角形边界；若在同侧，也无法严格包住 Q；若选中 Q 本身作顶点，同样不可能严格包含。因此没有合法三角形，而凸包四边形合法，最优答案为 4。

## 严格内部判定与整数实现

`inConvexStrict` 先排除外侧射线边界：

```text
cross(b[1]-b[0], Q-b[0]) > 0
cross(b[h-1]-b[0], Q-b[0]) < 0
```

再定位扇形，并要求 Q 严格处于对应凸包边内侧：

```text
cross(b[t+1]-b[t], Q-b[t]) > 0
```

内部对角线上的点仍属于凸包内部，定位二分使用 >=0；只有凸包边界需要排除。凸包不足三个顶点时直接判无解。

当前 Point<ll> 使用整数叉积，不需要 eps。坐标差绝对值至多 2×10^9，乘减的宽松绝对上界 8×10^18 仍在 long long 范围内。不能再将两个叉积相乘判断同号，否则可能溢出；本实现均直接比较符号。三点候选先求凸包再判严格内部，也处理了重复点、共线点与顶点顺序。

`getConvexHull(a)` 会排序 a，但 idx 在排序前已保存坐标对应的原始下标。扫描排序后的 a 寻找额外点仍合法，输出必须继续通过 idx 还原编号。

## 两次扫描修正与 WA 反例

```text
1
5 1
-2 -2
2 -2
2 2
-2 2
0 1
0 0
```

四个角点形成正方形，查询是中心，第五点 (0,1) 不在两条对角线上。合法最优答案为三角形下标 1,2,5。

1. 第一版只遍历 b 中四个凸包顶点，它们都在某条对角线上，永远找不到额外点，错误输出 4。
2. 修改循环范围和叉积操作数为 a 后，赋值仍为 `P = b[i]`，依然取错点。本例排序后有效候选位于 a[2]，却取到 b[2]，仍错误输出 4。若有效候选下标 i≥4，还会访问 b 越界。
3. 最终修复为 `P = a[i]`。本地复现由输出四边形变为合法三角形 1,2,5，修复后的源码与先前对拍通过版本一致。
