## 题意

序列价值为 a_1+a_n+sum(a_i xor a_(i+1))。每次可花费 C，将一个位置改为任意非负整数，求修改费用与最终序列价值之和的最小值。2<=n<=1e5，a_i<2^18，C<2^19，多测总 n<=2e5。

## 区间模型与正确性

固定两端值 x,y，中间所有相邻异或的和至少为 x xor y：逐位看，两端不同的位必须至少变化一次，每次变化贡献相应位权。将所有中间值设为 x 就能达到下界。

固定邻居 y，修改端点为 x 的局部贡献为 x+(x xor y)>=y，取 x=0 达到下界。因此修改端点时存在取零的最优方案。

把原序列编号改为 1..n，补 a_0=a_(n+1)=0。端点原有的线性贡献恰好变为与零的异或边。记 F[R] 为保留位置 R 的原值、处理到 R 的最小代价，F[0]=0。枚举上一个保留位置 L：

    F[R] = min_{0<=L<R} { F[L] + (R-L-1)C + (a_L xor a_R) }

任意实际方案按未修改的位置切段，费用至少为对应转移和；反过来，每个区间的下界都能构造达到。全修改对应从 0 直接转移到 n+1，所以无需额外枚举端点组合。结果为 F[n+1]。

## 高低位拆分维护

设 w_L=F[L]-LC，查询为：

    F[R] = (R-1)C + min_{L<R} { w_L + (a_L xor a_R) }

把 a 拆成 hi=a>>9、lo=a&511。异或可加性给出：

    a xor b = ((hi(a) xor hi(b)) << 9) + (lo(a) xor lo(b))

维护表 T[h][l]：历史高位等于 h 的所有位置中，w_L+(lo(a_L) xor l) 的最小值。注意代码里的 dp 是该查询表，不是公式中的一维 F。

- 插入值 a_L 和权重 w_L：高位 h 固定，枚举全部 512 种查询低位 l，更新 T[h][l]。
- 查询 a_R 的高低位 H,l：枚举历史高位 h，取 T[h][l]+((H xor h)<<9) 的最小值。

每轮先查询、再插入 F[R]-RC，保证候选严格满足 L<R。开始 upd(0,0) 对应左哨兵。最终右哨兵查询后也插入，虽不再使用但不影响结果。

## 复杂度与边界

每组初始化 O(2^18)，扫描 O(n*2^9)，空间 O(n+2^18)。多测总体要计入 T*2^18 的初始化开销。二维 long long 表约 2 MiB。

- F[L]-LC 可能为负，权重和表必须用有符号 long long。
- nC 可达约 5e10，不能用 int 保存 DP 或乘积；用户代码 C 为 ll，乘法会提升。
- a_i<2^18 保证高低位均在 [0,511]，补零哨兵同样合法。
- C=0 时可全改为零，答案应为 0。
- 不能仅按最小异或的普通 Trie 贪心，因为历史位置还有不同的附加权重。
- 将位数 B 均分时每次更新/查询 O(2^(B/2))，空间 O(2^B)；30 位等大值域不能照搬当前表。删除过期候选也不再能只维护 min。
