# 二分答案

## 奇偶子序列上的离散凸性

- [Gym106550J - 宝石商人](../training/2026/09/2026-09-07/CFGym106550J-Gem-Merchant/notes.md)
  - 固定奇偶性，让 t 每次增加 2，消除除以二的取整跳动；用单调差分证明凸性，二分第一个 F(t+2)>=F(t) 的点。
  - 当分段数量为常数时，可进一步枚举分段交点和端点附近，归档实现最终使用 O(1) 费用计算。

## 周期运动与可达性判定

- [CF1117C - Magic Ship](../training/2026/09/2026-09-02/CF1117C-Magic-Ship/notes.md)
  - 将时刻拆成“完整周期数 + 周期内前缀”，可以 `O(1)` 算出仅受周期运动影响的位置。
  - 距离本身不必单调；只要证明“当前可达则以后仍可达”，就能二分最早可达时刻。
  - 允许不操作时，`曼哈顿距离 <= 可用步数` 已是充要条件，不需要附加奇偶限制。
